[A) Backend Prompt (Spring)] Cases Detail 탭 API 확정(Proxy 권장) + OpenAPI 단일계약(P1)

파일 경로 / 생성 파일명:
- docs/prompts/PHASE_Cases_Backend_TabsProxy_P1.md (산출 문서)
- (코드) controller/service/client 패키지 내 신규/수정 파일 목록을 PR에 포함

목표:
- FE가 기대하는 탭 API(/api/synapse/cases/{id}/analysis|confidence|similar|rag/evidence)를 **BE가 제공**하고,
  내부적으로는 Aura(/aura/cases/{id}/*)를 호출해 프록시/어댑터로 반환한다.
- Tenant Scope(X-Tenant-ID), Authorization, (필요 시 X-User-ID) 를 BE에서 일원화하고,
  탭 조회에도 audit_event_log를 남길지(READ audit) 정책을 확정한다.

결론/결정안:
- 선택: “BE proxy(권장)”로 확정. FE의 호출 경로를 /api/synapse/** 하나로 고정한다.

Assumptions: Aura 서비스 baseUrl이 환경변수로 주입 가능하다.
Default: Aura 실패 시 BE는 표준 에러 계약(502/504 포함)으로 응답한다.

구현 범위(In/Out)
IN:
- GET /api/synapse/cases/{caseId}/analysis
- GET /api/synapse/cases/{caseId}/confidence
- GET /api/synapse/cases/{caseId}/similar
- GET /api/synapse/cases/{caseId}/rag/evidence
- (선택) GET /api/synapse/cases/{caseId}/stream/meta (SSE 직접 프록시가 어려우면 메타만 제공)
- OpenAPI 스펙 추가 + FE/BE 공통 enum/필드 키 고정

OUT:
- Aura의 trigger endpoint를 BE로 노출(보안 이슈로 2차)
  (단, 데모 필요하면 admin 메뉴에서만 호출 가능하게 별도 검토)

API 스펙(OpenAPI 스니펫)
paths:
  /api/synapse/cases/{caseId}/analysis:
    get: { summary: Case analysis, responses: { "200": { description: OK } } }
  /api/synapse/cases/{caseId}/confidence:
    get: { summary: Case confidence breakdown, responses: { "200": { description: OK } } }
  /api/synapse/cases/{caseId}/similar:
    get: { summary: Similar cases, responses: { "200": { description: OK } } }
  /api/synapse/cases/{caseId}/rag/evidence:
    get: { summary: RAG evidence list, responses: { "200": { description: OK } } }

백엔드 작업(필수)
1) AuraClient 구현
- baseUrl: 환경변수(AURA_BASE_URL 등)로 주입
- 헤더 전달: X-Tenant-ID, Authorization, (필요 시 X-User-ID)
- timeout(권장 3~5s) + retry(1회) + (가능하면) circuit breaker

2) Controller/Service 추가
- 위 4개 endpoint에서 AuraClient 호출 결과를 그대로 반환(필드명/타입 유지)
- DTO는 “Aura 응답 스키마”를 그대로 매핑하거나, 최소 공통 DTO로 캡슐화

3) Audit(정책 결정)
- 옵션 A(권장): 탭 조회도 READ audit 남김
  - event_type: CASE_VIEW_ANALYSIS / CASE_VIEW_CONFIDENCE / CASE_VIEW_SIMILAR / CASE_VIEW_RAG
- 옵션 B: 목록/상세/연관조회만 남김(탭은 제외)

4) Error contract
- Aura 404 -> 404 passthrough
- Aura 401/403 -> 401/403 passthrough
- Aura 5xx -> 502
- Aura timeout -> 504

완료조건(DoD)
- curl로 4개 endpoint 호출 시 200 응답(최소 empty state 구조) 반환
- X-Tenant-ID가 없으면 표준 에러 처리(프로젝트 규칙)
- FE에서 탭 클릭 시 /api/synapse/** 로만 호출됨

검증용 curl(예시)
curl -H "Authorization: Bearer <TOKEN>" -H "X-Tenant-ID: 1" \
  "http://localhost:8080/api/synapse/cases/CS-1/analysis"

curl -H "Authorization: Bearer <TOKEN>" -H "X-Tenant-ID: 1" \
  "http://localhost:8080/api/synapse/cases/CS-1/confidence"
